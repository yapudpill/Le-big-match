# Projet de bases de données : Le Big Match

*par Anthony Fernandes et Marc Robin*

## Utilisation

Pour charger la base de données, executez successivement les fichiers
`tables.sql` puis `remplissage.sql` qui, comme leur nom l'indique, créent les
tables de la base puis les remplissent avec les données du dossier `data`.

Vous pouvez ensuite executer les fichiers `requetes.sql`, contenant une vingtaine
de requêtes variées sur la base, et `matching.sql`, qui affiche les
recommendation de rencontre pour un utilisateur donné.
